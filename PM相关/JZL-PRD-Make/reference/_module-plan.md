### 说明
- 如果选中模板为`JZL-PRD-Make/templates/PRD-L2`，`JZL-PRD-Make/templates/PRD-L3`，`JZL-PRD-Make/templates/PRD-L4`，因为`核心功能模块详述`部分可能包含多个模块，要求每个模块都要按照模板规则来写，每个功能模块要包含：目标、用户故事、流程、页面与交互、业务规则和验收标准，其中页面与交互要包含：页面、状态说明。
- 其他部分的格式根据选中模块确定。

## 写作约定
- 文档定位：`prd/PRD.md`，单文件追加；每次只追加一个模块，不重写前文。
- 写法：表格优先 + Mermaid 流程/状态/ER 图 + 验收标准（Given/When/Then）。
- 不确定项以 `[待确认：...]` 标注，不编造。
- 每追加一个模块，更新 `prd/_append-log.md`，并输出本模块摘要 + 待确认点，等用户确认后继续。
- 复杂度 L4 但 MVP 范围已收敛（不做云同步、不做移动端、不做协作），因此**省去**大型平台 PRD 才需要的"组织/治理/计费/审计/合规"等章节，避免堆砌。
